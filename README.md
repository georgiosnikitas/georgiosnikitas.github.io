# georgiosnikitas.github.io

Personal software studio website for Georgios Nikitas — an indie software maker shipping small, focused products for individuals and small businesses.

## Products

- **Brain Break** — AI-powered terminal quiz app (CLI, one-time purchase)
- **Brain Break Mobile** — Mobile version of Brain Break for iOS & Android (coming soon)
- **Auto Garage** — Self-contained web app for managing an auto repair garage (PWA, one-time license)

## Structure

- `index.html` — Main landing page with product listings, pricing, demos, FAQ, and contact info
- `brain-break-mobile-mockups.html` — Mobile mockup designs for Brain Break Mobile
