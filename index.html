Brain Break · AI-powered CLI quiz app

Brain Break

Brain Break is an AI-powered terminal quiz app built with TypeScript. Define quiz domains, answer AI-generated questions, and review your score progression and history — all from a CLI interface. Choose from multiple AI providers including OpenAI, Anthropic, Google Gemini, GitHub Copilot, Ollama for local models, or any OpenAI-compatible endpoint.

⚙️ Installation

📦 From npm

npm install -g brain-break

🍺 Homebrew (macOS)

brew trust georgiosnikitas/brain-break
brew tap georgiosnikitas/brain-break
brew install brain-break
✨ Features
  • Multiple AI providers — OpenAI, Anthropic, Google Gemini, GitHub Copilot, Ollama (local LLMs), and any OpenAI-compatible endpoint
  • Domain-based quiz sessions — create any topic like java-programming, greek-mythology, or thai-cuisine
  • AI-generated questions — multiple-choice questions with automatic deduplication
  • Adaptive difficulty — scoring and difficulty progression based on correctness and response speed
  • Explain answer — ask the AI to explain why the correct answer is right after any question
  • Teach me more — drill deeper with AI-generated micro-lessons after viewing an explanation
  • Question bookmarking — bookmark any answered question from the quiz or history for later revisiting via a dedicated bookmarks view
  • My Coach — AI-generated coaching report per domain analyzing your question history to surface strengths, weaknesses, trajectory, and recommendations
  • Domain sub-menu — play, challenge, history, bookmarks, stats, my coach, ASCII art, archive, and delete per domain
  • Stats dashboard — per-domain score trend, accuracy, and return streak
  • ASCII art milestone — unlock FIGlet ASCII art per domain
  • Configurable language and tone — language selection for questions and explanations, plus seven tone options including humorous, sarcastic, and pirate
  • Dark and light themes — toggle between dark and light terminal background modes for readable colors on any terminal
  • Settings screen — change provider, model, language, tone, my coach scope, theme, and welcome screen at any time
📋 Requirements
  • Node.js >= 22.0.0
  • An AI provider configured through the in-app settings:
    • Anthropic — ANTHROPIC_API_KEY environment variable
    • OpenAI — OPENAI_API_KEY environment variable
    • Google Gemini — GOOGLE_GENERATIVE_AI_API_KEY environment variable
    • GitHub Copilot — active Copilot subscription and authentication in the environment
    • Ollama — a running Ollama instance
    • OpenAI-compatible API — OPENAI_COMPATIBLE_API_KEY environment variable. Use for any service exposing an OpenAI-compatible chat completions endpoint (e.g. Azure OpenAI, Groq, Together AI, Mistral, Perplexity, DeepSeek, LM Studio, vLLM).
🚀 Platform & delivery
  • Cross-platform CLI — runs on macOS, Linux, and Windows wherever Node.js 22+ is available
  • Installed from npm or Homebrew; on first run, the app offers to enter an existing license key or purchase one
  • Updates included for the purchased major version
📜 License
  • Single-user, personal-use license
  • Non-transferable; AI provider usage and any associated API costs are the buyer's responsibility

Commit Whisper · Deterministic git history analysis

Commit Whisper

🕵️ I know what you did last commit. Commit Whisper (commit-whisper) is a terminal-native CLI that performs deterministic git history analysis with a grounded, bring-your-own-key AI narrative. It analyzes a local or remote git repository, computes a catalog of deterministic metrics — with no AI — and, when an AI provider is configured, adds a grounded AI narrative and coaching report. Output renders to HTML, Markdown, terminal, and JSON from a single canonical Report JSON.

⚙️ Installation

📦 From npm

npm install -g commit-whisper

🍺 Homebrew (macOS)

brew trust georgiosnikitas/commit-whisper
brew tap georgiosnikitas/commit-whisper
brew install commit-whisper
✨ Features
  • Deterministic metrics (no AI) — six metric groups computed straight from git history, so the same repository always produces the same, verifiable numbers:
    • Group A · Cadence — commit frequency, timing, and activity rhythm over time
    • Group B · Contribution & ownership — author contribution mix and how code ownership is distributed
    • Group C · Commit message quality — message length, structure, and convention signals
    • Group D · Branching & merge structure — merge patterns and branch topology
    • Group E · Code churn & hotspots — the files that change most often and where churn concentrates
    • Group F · Repository health signals — aggregate signals summarizing overall repository health
  • Grounded AI narrative & coaching (optional, bring-your-own-key) — when an AI provider is configured, Commit Whisper layers an explanatory narrative and coaching report on top of the metrics, with safeguards that keep it anchored to the data:
    • Three-part narrative plus four-facet, per-metric explanations
    • Per-group batched generation for focused, relevant prose
    • Provider reachability preflight before any request is made
    • Deterministic grounding verification pass so every claim stays tied to the computed metrics
    • Confidence self-assessment with escalation when the model is unsure
    • Works with OpenAI, Anthropic, Gemini, Ollama, or any OpenAI-compatible endpoint, using your own API key
  • Multiple output formats — renders to HTML, Markdown, terminal, and JSON from a single canonical Report JSON, so every format stays consistent with the same underlying data
  • Local & remote repositories — analyze a repository on disk, or clone and analyze a remote one in a temporary workspace that is cleaned up afterward
  • Terminal-native & scriptable — a fast CLI with clear exit codes, equally suited to interactive use or automation in CI pipelines
  • Privacy-first — the AI step is entirely optional, and your BYOK AI keys and git tokens never leave your machine
📋 Requirements
  • Node.js >= 22.0.0
  • npm (bundled with Node.js)
  • A system git available on PATH
  • Optional: an AI provider configured with your own API key for the narrative and coaching report
🚀 Platform & delivery
  • Cross-platform CLI — runs on macOS, Linux, and Windows
  • Install from npm or Homebrew, or with a prebuilt self-contained binary (no Node.js required)
  • Updates included for the purchased major version
📜 License
  • MIT-licensed CLI and source code
  • Paid tiers — Single (single user) and Unlimited (unlimited users for teams) — enforced at runtime via an online license check
  • BYOK AI keys and git tokens stay on your machine; AI provider usage and any associated API costs are the buyer's responsibility
Moodito · Privacy-first macOS menu bar mood mirror

Moodito

Moodito is a tiny, privacy-first macOS menu bar companion that reads your face through the webcam and shows how you're feeling right now — as a friendly emoji and label — without ever leaving your Mac. No accounts, no cloud, no frames uploaded anywhere: every detection happens 100% on-device. Beyond the live emoji, it quietly builds a picture of your emotional day, turns it into beautiful in-menu charts, and — if you connect your favourite AI provider — writes you a personalised wellbeing report. Emotion recognition is powered by Google's MediaPipe Face Landmarker, mapping facial blendshapes to a small set of emotions: happy, sad, surprised, angry, and neutral.

📦 Download the standalone Moodito.app from the GitHub releases, or build it yourself from source.

✨ Features
  • Live emotion in the menu bar — your current mood shown as an emoji + label (e.g. 😀 happy), refreshed several times a second, with a Detected row showing the recognised emotion and its confidence
  • Insights submenu — a rich, at-a-glance dashboard built entirely from your own on-device history: an activity chart by hour of day, a per-emotion heatmap, and a statistics table of time spent and occurrences for every state
  • Selectable date range — insights cover a live, sliding Last 24 Hours window by default; with an active license you can compute them over any custom Since / Range you like
  • AI-powered Mood Tip — ask your configured AI provider for a detailed, personalised wellbeing report over your selected range, and Save as PDF to export a polished, branded report with a full per-emotion breakdown
  • Bring your own AI provider — connect Anthropic, Gemini, OpenAI, any OpenAI-compatible endpoint, or local Ollama; credentials are stored locally and a built-in Test button verifies the connection
  • Adjustable sensitivity — fine-tune detection per emotion (Low / Normal / High) so Moodito reads your face the way you want
  • Customisable display — toggle Show Emojis and Show Labels independently, or fall back to the clean Moodito icon
  • Pause / Resume — instantly stop processing webcam frames whenever you want privacy or a break, with a one-click camera-access helper
  • Export & erase — download your raw detection log as CSV, or erase all collected data at any time. Your data, your call
📋 Requirements
  • macOS
  • A webcam
  • Python 3.11–3.13 when running from source (the standalone Moodito.app bundles its own runtime)
  • Optional: an AI provider configured with your own API key for the Mood Tip wellbeing report
🚀 Platform & delivery
  • macOS menu-bar-only app — small, fast, and out of your way
  • Download the prebuilt Moodito.app from GitHub releases, or build it from source with the bundled script
  • Everything except the optional Mood Tip stays entirely on your Mac; only the Mood Tip contacts the AI provider you explicitly configure
  • Updates included for the purchased major version
📜 License
  • Single-user, personal-use license
  • A license unlocks custom date ranges for the Insights; without one, the insights stay pinned to the live Last 24 Hours window
  • Non-transferable; AI provider usage and any associated API costs are the buyer's responsibility
